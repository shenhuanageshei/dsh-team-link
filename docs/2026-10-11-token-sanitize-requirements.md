# 需求档 · 框定 token 消毒面（dsh-team-link 批 E）

> **状态**：待用户确认（2026-10-11 立项，用户原话「建议二立项」）。配对设计档 `docs/2026-10-11-token-sanitize-design.md`。
> 章节口径＝全局 `~/.dsh/AGENTS.md` 第四节「设计文档的必备章节」。
> **起因**：用户报告 `team-link-bac-1009-coordinator-40301798` 每次发团队消息**有几率**失败（`tool input is invalid JSON`）。
> 父侧取证后确认这是**会自传播的流级故障**，本次立项的是其中**我们能管的那一层**（详见设计档 §2）。

## 〇、三句话（给用户）

1. **这事是什么**：DeepSeek 的**框定 token**（一个特殊 token，不是普通文字）有时候会漏进工具调用的**参数内容**里；流式解析器把它当成「又来一次工具调用」，参数串就断了 ⇒ 整个回合报 `tool input is invalid JSON` 而死。
2. **对我们有什么影响**：它**漏出来一次就留在对话里**，模型看得见自己上次那串 ⇒ **接着复现** ⇒ 看起来"有几率"，实际是**越撞越死**（实测某个会话连死 4 个回合）。
   而本插件的 `team_link_team_append` 是**最大触发面**（29 次失败里 15 次），因为它要模型在参数里写一大段中文。
3. **建议怎么办**：**我们修不了触发层**（那在流式解析器里），但能**堵住传播层** ——
   让那个 token **永远不经过本插件的任何出口**回流进上下文（工具结果 / 跨会话投递正文 / 摘要与告警 / 状态卡 / 提示词段），入口也一并处理（别把它写进黑板，否则以后每次读都会被再喂一次）。

## 一、总体目标（一段话）

让本插件的**每一个文本出口**都成为**消毒面**：框定 token（及其包裹结构）经过时被**替换成固定占位符**，替换处数**由占位符自身呈现**（v1.1：命中多处时带编号，见设计档 §6.5 —— **不改回执、不加累加器、不新增 import**）；
黑板（decisions / tasks / discipline）在写入前也做同样处理，**保证黑板上不存在那个 token**，从而**切断「读黑板 ⇒ 上下文被污染 ⇒ 模型复现 ⇒ 回合死」这条回路**。
**一句话**：插件的所有出口与入口都不再搬运那个 token。

| # | 用户故事 | 验收指向 |
| --- | --- | --- |
| US-E1 | 作为**用户**，我希望**一次失败的后果不要扩散**：某个会话漏出 token 之后，黑板里**不会**因此多出一条带 token 的裁决（否则全队每次读黑板都被再喂一次） | FR-1 / U1 |
| US-E2 | 作为**用户**，我希望**任何工具结果**都不带 token 回流 —— 不管是 `team_read` 读出来的、`status` 显示的、还是 `send`/`append` 回执里回声的 | FR-2 / U2 |
| US-E3 | 作为**协调者**，我希望**跨会话投递的正文**（`team_link_send`）也不搬运它 —— 否则我一次失手的产物会污染**收件人**那个会话 | FR-3 / U3 |
| US-E4 | 作为**用户**，我希望**提示词面**（角色段 / 资源行上下文）同样干净 —— 它每回合都进请求，是最不该带毒的地方 | FR-4 / U4 |

| US-E6 | 作为**维护者**，我希望这条消毒是**一处实现、多处使用**（不是十处各写一遍），且**源码/文档里不出现那个原串**（逐字写它本身就是自伤 —— 父侧今天栽了两次） | FR-6 / U6 |

## 三、明确的非目标（本批不做）

| # | 不做的事 | 为什么 |
| --- | --- | --- |
| NF-1 | **不修触发层**（流式解析器把参数内容里的 token 当成新边界） | 那在宿主 / 适配器里，不在本仓；本批只堵传播面（另出观测报告给平台侧） |
| NF-2 | **不改** `team_link_team_append` 的长度上限或输入形态 | 那是**批 F（建议三）**，已单独立项；两批**不得互相夹带** |
| NF-3 | **不改**任何工具名、参数名、返回结构（除了被替换的字符本身） | 本批是**消毒**，不是改接口 |
| NF-4 | **不追溯改写**已经落盘的黑板历史（只保证**新写入**与**读出**干净） | 历史文件是事实记录；要清旧账得单独一次人工动作，不在本批 |
| NF-5 | **不**把 token 替换成"看起来像它"的东西（如带 DSML 字样的占位符） | 占位符自己也可能被解析器认出来；必须换成一个**完全无关**的固定串 |

## 四、验收面（用户可见）

1. 在任一团队会话里，**读出**一条本来含 token 的黑板行 ⇒ 显示为占位符，且回执里有一句「已替换 N 处」。
2. 用 `team_link_team_append` 写入一条含 token 的正文 ⇒ **落盘的黑板文件里不含那个 token**（占位符代替），回执如实报出替换处数。
3. 10 个 `team_link_*` 工具的**任意一个**返回文本里，都不含该 token 的包裹结构（用一个带毒的夹具值逐个扫）。

## 五、非功能标准（NFR）

| # | 标准 | 判据 |
| --- | --- | --- |

| NFR-5 | **一处实现**：消毒只写在**一个**函数里，出口靠既有收口点挂载 | U2/U6 |
